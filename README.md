# MOONBOUND — 月影のヴァルキュリア

月夜の遺跡を冒険する、スマートフォン対応のブラウザ3DアクションRPG。

## ゲーム内容

- 全24人の成人オリジナルキャラクター：日本アイドル系、K-pop系、綺麗系、グラマラス系が各6人。
- キャラクター2人を編成。組み合わせによって変わる絆の合体技。
- 3D移動・攻撃・回避・スキル。勝利で経験値、星晶石、ゴールド、アイテムを獲得。
- レベルアップ報酬、武器強化、ゲーム内通貨のガチャ。SSR排出率12%、最大30回でSSR確定。
- 常設イベント3種。初回クリアで仲間が加入。
- 自動保存、セーブファイルの書き出し・読み込み。

## 操作

PC：WASD / 矢印キーで移動、Zで攻撃（長押し可）、Xでスキル、Cで合体技、Spaceで回避。画面ドラッグで視点変更。

スマホ：左下のスティックで移動、右下の攻撃ボタンを長押しで連続攻撃。スキル・合体技・回避は各ボタンをタップ。戦闘は画面全体に表示し、縦・横画面に対応。WebGL対応ブラウザが必要です。

## ローカル開発

Node.js 20以上。

```sh
npm ci
npm run dev
```

`http://localhost:4173` を開きます。別のポートは `PORT=4174 npm run dev`。

```sh
npm test
npm run build
```

依存パッケージやバンドル処理は不要です。Three.jsを同梱し、完成したゲームは `dist/` にあります。GitHub Actionsでゲームロジックと静的アセットを確認します。

## Vercel

GitHubリポジトリをVercelにImportします。Framework PresetはOther、Root Directoryはリポジトリのルート。`vercel.json` がビルドコマンド `npm run build`、出力ディレクトリ `dist` を設定します。環境変数は不要です。

Git連携後は `main` の更新で本番デプロイ、その他のブランチやPRでプレビューが作成されます。

## セーブについて

進行はブラウザのlocalStorageに保存します。別端末・別ブラウザ・別URLでは共有されません。Sites版から移す場合は、旧URLの「セーブ管理」で書き出し、新URLで読み込んでください。ブラウザのデータ消去前にも書き出しをおすすめします。

## 技術・制限

HTML / CSS / JavaScript / Three.js r170で実装。サーバー、ログイン、課金、オンラインランキングはありません。リアルな生成イラストと簡易的なプロシージャル3Dモデルを使用します。イベントは常設で、ライブサービスの自動配信ではありません。装備ドロップはコレクションで、武器強化は素材とゴールドを消費します。

スマホ相当のブラウザで縦・横画面、マルチタッチ、320px幅を確認済み。iOS / Androidの実機は未検証です。
