# MOONBOUND — 月影のヴァルキュリア

## アプリの概要

MOONBOUNDは、月夜の遺跡を舞台にしたスマートフォン・PC対応のブラウザ3DアクションRPGです。仲間を召喚して2人のパーティーを編成し、移動・攻撃・回避・スキル・絆の合体技を使って敵を倒します。勝利で得た経験値やアイテムで仲間を育て、次の冒険やイベントに挑みます。

インストール不要で、WebGL対応ブラウザから遊べます。

## 機能概要

- 全24人の成人オリジナルキャラクター：日本アイドル系、K-pop系、綺麗系、グラマラス系が各6人。
- キャラクター2人を編成。組み合わせによって変わる絆の合体技。
- 3D移動・攻撃・回避・スキル。勝利で経験値、星晶石、ゴールド、アイテムを獲得。
- レベルアップ報酬、武器強化、ゲーム内通貨のガチャ。SSR排出率12%、最大30回でSSR確定。
- 常設イベント3種。初回クリアで仲間が加入。
- 自動保存、セーブファイルの書き出し・読み込み。

## 操作方法

ホームの「冒険を始める」で戦闘を開始します。すべての敵を倒すと勝利。戦闘中は「撤退」で戻れます。

| 操作 | PC | スマートフォン |
|---|---|---|
| 移動 | WASD / 矢印キー | 左下のスティック |
| 通常攻撃 | Z（長押し可） / 画面クリック | 右下の攻撃ボタン（長押しで連続攻撃） |
| 範囲スキル | X | スキルボタン |
| 絆の合体技 | C | 合体技ボタン |
| 回避 | Space | 回避ボタン |
| 視点変更 | 画面をドラッグ | 操作ボタン以外の画面をドラッグ |
| 撤退 | 右上の撤退ボタン | 右上の撤退ボタン |

スマホの戦闘は画面全体に表示し、縦・横画面に対応します。光るクリスタルに近づくとHPが回復します。スキルと合体技には再使用までの待ち時間があります。

### 召喚・編成・育成

1. 「召喚」で星晶石を使い、1回または10回召喚します。重複した仲間は強化素材に変換されます。
2. 「ヴァルキュリア」で加入済みの仲間を選び、先頭と相棒を編成します。先頭の仲間を操作し、相棒と合体技を使います。
3. 同じ画面で強化素材とゴールドを使って武器を強化できます。
4. 「イベント」で月夜の仮面舞踏会・幽霊船の星時計・紅蓮の闘技大会に挑戦できます。初回クリアで仲間を獲得します。


## ローカル開発

Node.js 20以上。

```sh
npm ci
npm run dev
```

`http://localhost:4173` を開きます。別のポートは `PORT=4174 npm run dev`。

```sh
npm test
npm run build
```

依存パッケージやバンドル処理は不要です。Three.jsを同梱し、完成したゲームは `dist/` にあります。GitHub Actionsでゲームロジックと静的アセットを確認します。

## Vercel

GitHubリポジトリをVercelにImportします。Framework PresetはOther、Root Directoryはリポジトリのルート。`vercel.json` がビルドコマンド `npm run build`、出力ディレクトリ `dist` を設定します。環境変数は不要です。

Git連携後は `main` の更新で本番デプロイ、その他のブランチやPRでプレビューが作成されます。

## セーブについて

進行はブラウザのlocalStorageに保存します。別端末・別ブラウザ・別URLでは共有されません。Sites版から移す場合は、旧URLの「セーブ管理」で書き出し、新URLで読み込んでください。ブラウザのデータ消去前にも書き出しをおすすめします。

## 技術・制限

HTML / CSS / JavaScript / Three.js r170で実装。サーバー、ログイン、課金、オンラインランキングはありません。リアルな生成イラストと、関節を持つプロシージャル3Dモデルを使用します。人物画像をモデルの顔へ投影する処理は撤去し、顔のパーツは立体形状で描画します。歩行は移動距離と連動し、攻撃は構え・振り・戻しを滑らかにつなぎます。全LODで姿勢を同期し、髪・マントの揺れを制限しています。

現段階はプロトタイプです。モンスターハンター等に近い品質に必要なモデル、PBR素材、骨格、モーション、物理、最適化の技術は [リアルな3D表現の制作ガイド](docs/REALISTIC_3D.md) にまとめています。

イベントは常設で、ライブサービスの自動配信ではありません。装備ドロップはコレクションで、武器強化は素材とゴールドを消費します。

スマホ相当のブラウザで縦・横画面、マルチタッチ、320px幅を確認済み。iOS / Androidの実機は未検証です。
